# Figbird Devtools privacy policy

Last updated: 10 August 2026

Figbird Devtools is a developer tool for inspecting Figbird state in the page whose browser developer tools are open.

## Data the extension handles

While its Figbird panel is open, the extension reads Figbird diagnostic data from the inspected page. This can include query descriptors and results, realtime event payloads, fetch and write activity, timing information, and errors. Depending on the application being inspected, that information may include website content or personal data visible to the signed-in developer.

The extension uses this information only to render its developer-tools interface and to let the developer inspect the corresponding page elements.

## Storage and sharing

All diagnostic data is processed locally in the browser. The extension does not send it to Humaans, Figbird, analytics providers, advertisers, or any other third party. It does not use remote code, analytics, advertising, accounts, cookies, or browser storage. Diagnostic data is held only in memory and is discarded when the developer-tools session ends or the page reloads.

Humaans does not have access to the inspected data and does not sell or use it for advertising, profiling, credit decisions, or any purpose unrelated to the extension's single developer-tools function.

## Changes and contact

Material changes to this policy will be published with an extension update. Questions or privacy requests can be filed in the [Figbird GitHub repository](https://github.com/humaans/figbird/issues).
