Figbird caches data and applies realtime events for React + Feathers applications.

After code changes, run:

- `npm run tsc` for types
- `npm run lint` for lint
- `npm run ava` for tests
- `npm run test` for the full suite

Prefer precise types over `any`. If `any` is necessary for a public API or test, use a focused `oxlint-disable-next-line` comment.
